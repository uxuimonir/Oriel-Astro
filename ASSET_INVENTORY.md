# ASSET_INVENTORY.md

## Photography

62 original Framer photographs, pulled from the project's own asset store and stored in `public/photos/` under their original Framer hashes. No substitutes, no stock added.

- Home / shared: hero camera frame, statement cliff, cinematic sunset, contact lighthouse, 4 commission images, 4 quote portraits, 5 journal covers.
- Studio: tripod-on-the-shore hero.
- Journal index: camera-on-table header.
- Series: 7 frames per series × 6 series = 42 frames (Opening, Establishing, Detail, Wide, Motion, Quiet, Closing).

Each file was resized to a 2000px long edge and re-encoded at quality 82 for delivery (65MB → 19MB). Aspect ratios are untouched; ratio per frame is carried in the data file (`portrait` / `landscape` / `square`) and applied with CSS `aspect-ratio`, so cropping matches the original.

## Type

Archivo, Instrument Serif and DM Mono, loaded from Google Fonts with `preconnect`. Same families as the Framer project.

## Icons / logo

The Oriel mark is the original CSS shape from Framer (a half-round outline), not an image. `lucide-astro` is installed for any icon need; no decorative icons exist in the original design.

## Credits

Photographs are free-licence work by the photographers named in the Framer file's own credits line, which is reproduced verbatim in the footer.
